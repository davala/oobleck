# Oobleck - an Homage to the Oblique Strategies

## Project Identity
A web-based homage to Brian Eno and Peter Schmidt's Oblique Strategies 
card deck (1975). Presents one strategy at a time, chosen randomly or 
on demand. Personal project — aesthetic fidelity to the original matters 
more than feature richness.

## Tech Stack
- Vanilla HTML, CSS, JavaScript — no frameworks, no build tools
- No npm, no dependencies
- Target: modern evergreen browsers only

## Design Intent
Austere and typographic. The original cards were plain black text on 
white. Resist the urge to over-design. Any deviation from minimalism 
needs a strong reason.

## Conventions
- Single-file preferred where practical
- CSS custom properties for any theming
- No JavaScript frameworks — DOM manipulation only
- Readable over clever

## Hard Constraints
- Do not introduce any external dependencies without asking
- Do not add analytics, tracking, or any third-party scripts

## Running the Project
Open index.html directly in a browser — no server needed.
